# April 29, 2024 - Unit 6.1 - APIs
---

## Overview
In today’s lesson, students will be introduced to JSON traversal and the fundamentals of making API requests with the Requests library, using the OMDb and New York Times APIs.
---

## Class Objectives
By the end of this lesson, the students will be able to:
- Make get requests with the Request library.
- Convert JSON into a Python dictionary.
- Read and apply API documentation.
- Sign up for and use an API key.
